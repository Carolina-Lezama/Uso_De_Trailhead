# Primeros pasos con las solicitudes
El proceso de creación e iteración de solicitudes se denomina diseño de solicitudes. Del mismo modo que los chefs perfeccionan sus recetas mediante pruebas y ajustes, usted debe revisar las respuestas del LLM e iterar las solicitudes hasta obtener resultados precisos y de alta calidad.

Las solicitudes no son lo único que puede influir en el resultado de un LLM. Los LLM también tienen configuraciones que influyen en sus respuestas. Cuando diseñe las solicitudes, asegúrese de experimentar con la configuración del LLM para ver cómo afectan los diferentes valores al resultado.

Por último, tenga en cuenta que los LLM no responden siempre igual a las solicitudes. Diferentes LLM pueden responder de manera diferente a una misma solicitud. Al igual que los ayudantes culinarios, cada LLM recibe entrenamiento por parte de expertos diferentes, con datos y técnicas de enseñanza diferentes. Para obtener resultados óptimos, siempre debe conocer al LLM con el que trabaja y adaptar sus solicitudes a dicho modelo.

# Comprender las plantillas de solicitud

Básicamente, una plantilla de solicitud es una solicitud que se puede volver a utilizar. Se trata de plantillas que incluyen marcadores de posición para detalles específicos sobre clientes, productos, etc. Cuando los marcadores de posición se completan con datos reales y adecuados, la plantilla de solicitud se convierte en una solicitud realmente personalizada. El contenido y las instrucciones son prácticamente los mismos, pero el resultado se adapta a su negocio y a su audiencia objetivo.

Las plantillas de solicitud ayudan a los equipos a generar resultados coherentes y basados en datos a gran escala. El uso de este tipo de plantillas es ideal para las comunicaciones B2C, ya que proporcionan una voz coherente y un resultado personalizado. También ayudan a los equipos a enfocarse en completar las tareas, en lugar de crear solicitudes individuales de manera repetida. Cree una plantilla de solicitud una sola vez y genere innumerables versiones de contenido personalizado para las diferentes audiencias.

"Conozca a su audiencia" es un dicho conocido para cualquiera que trabaja como escritor o presentador. Significa que tiene que cambiar su forma de comunicarse en función de quién escuche, lea o vea su contenido. Para que el LLM conozca a la audiencia, debe describirla. Pero lo más importante es informarle al LLM quién enviará el mensaje. 

Observe que Lara basa su plantilla de solicitud en los datos de CRM al incluir campos de combinación. De este modo, el LLM puede utilizar la duración de la relación con el cliente como orientación para el contenido. 

Es muy importante incluir algunas salvaguardas para indicarle al LLM los límites de lo que puede hacer. Por ejemplo, debe indicar que el contenido no debería contener suposiciones si falta información. También le conviene definir la longitud del contenido. 

Si ya usó herramientas de IA generativa, sabe que crear una solicitud es una tarea un tanto artística. Incluso cuando la solicitud parece clara, es muy frecuente que el contenido generado no sea del todo correcto.

es recuerda que deben comprobar las respuestas cada vez que utilicen la plantilla para generar resultados. Se trata de una de las mejores prácticas conocida como "interacción humana" y es un requisito para una IA generativa digna de confianza.

# Crear y justificar las plantillas de solicitudes
Hacer que las plantillas sean específicas las hace efectivas. Otra forma de decir “específica” es decir que su plantilla está justificada.

Si desea usar datos de una consulta SOQL o una API externa en su solicitud, considere el uso de Apex. Apex también es eficaz si desea generar un archivo JSON con formato correcto o filtrar datos de manera programática.

# Crear una plantilla de solicitud de generación de campos

Una plantilla de solicitudes de generación de campos es un tipo específico de plantilla de solicitud que está diseñada para devolver una respuesta generada de un LLM a un campo específico en un registro. Las plantillas de solicitud de generación de campos tienen una relación directa con los campos de registro.
