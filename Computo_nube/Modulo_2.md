# Tipos de nube

## Nube publica
para multiples usuarios, la infraestructura es compartida, pero cada organizacion tiene todo separado

## Nube privada
Exclusiva para una sola organizacion, da mucho mas control, usado principalmente en el manejo de informacion sensible 

## Multinube
Utilizar servicios de diferentes provedores segun sus necesidades especificas

## Nube hibrida
Infraestructura publica y privada, usada para proteger datos sensibles y los servicios publicos para datos no tan sensibles, es decir, categoriza que es necesario proteger mas

# AIaaS
Ia as a service

ya no es necesario un enorme centro de datos, para desarrollar soluciones basadas en ia, ofrece la infraestructura

# Edge computing
implementar un servidor local que analise la informacion sin mayor retraso, el procesamiento importante se realice lo mas pronto posible
